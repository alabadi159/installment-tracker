# Installment & Loan Manager

A modern local-first tool for tracking installment plans, upcoming payments, and outstanding balances with a clean dashboard experience.

> Local SQLite Connected (Native / WebSQL)

## Overview

This app helps you manage recurring debt and payment obligations in one place. It tracks:

- active installment plans
- upcoming due dates
- total unpaid balance
- overdue payments
- payment status and progress
- vendor/provider information
- local persistence with SQLite/WebSQL support

## Why it stands out

- Clean dark dashboard inspired by modern finance tools
- Quick balance overview for current month and overdue items
- Search and filtering for plans and providers
- Local-first storage for private and fast access
- Ready for web and Android packaging via Capacitor

## Dashboard highlights

- Total unpaid balance
- Current month required payments
- Active plans count
- Completed plans count
- Supported providers and loan categories
- Immediate upcoming payment list
- Active installment overview with progress bars

## Tech stack

- React + Vite
- JavaScript / React UI
- Tailwind CSS
- Capacitor
- Android build support
- Local SQLite / WebSQL storage

## Features

- Track installment plans by provider and category
- Monitor due dates and overdue items
- View real-time payment progress and remaining balances
- Filter plans by provider, status, and date
- Keep data local for privacy and speed
- Export / import support
- Build-ready Android packaging

## Getting started

### Prerequisites

- Node.js 22+
- npm
- Java 21 (for Android builds)

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

### Production build

```bash
npm run build
```

### Sync Capacitor Android project

```bash
npx cap sync android
```

### Build Android APK

```bash
cd android
chmod +x ./gradlew
./gradlew assembleDebug
```

On Windows PowerShell:

```powershell
cd android
.
graduw.bat assembleDebug
```
